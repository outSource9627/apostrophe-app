Student app · Interests tab · four options

Interests: A / B / C / D

The Interests tab shows employers' Interests sent to the student: pending ones with a clock, the Accept / Decline answer, and a permanent closed list. Accepting opens a connection and a chat. Today the tab is one screen with a link to a pushed Connections screen. All four options use only today's fields, actions and copy; names, dates and numbers are placeholder samples. Rules such as expiry and cooldown come from /config (employer.interest.expiryDays, cooldownDays) and are shown with sample values (14 and 30) in this mockup only. Proposal marks anything the app does not do today.

  • Same system as the approved screens: Geist / Geist Mono, large title collapsing to a compact bar (scroll the phone), 18-radius bordered panels, 46-high buttons, floating tab bar, no shadows. Accept and Open chat are ink (not violet) because several cards can show them at once.
  • Try it: pick an option, switch the state above the phone, tap Accept / Decline, expand rows, tap Block. Use Compare all 4 for a side-by-side.
