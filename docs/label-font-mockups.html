Small labels — font options

Today every small label in the app and the web is set in Geist Mono, in capitals with wide letter spacing (“SAVED · 3:41 PM”, “STEP 3 OF 6”, “IT · 11–50 · PUNE”). Below, the same real screens are drawn in different fonts. Pick a font in the bar; it redraws everything. Numbers (timers, clocks, codes, note stamps) can follow the same font with fixed-width digits, or stay in Geist Mono. Apply to lets you see the font on labels only (the rest stays Geist, as now) or on the whole screen.
