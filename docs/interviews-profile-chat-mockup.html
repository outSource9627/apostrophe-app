Candidate · My interviews · Profile · Chat

Four designs for each screen

All content is what the app already shows — statuses, fields, rules and empty states. Names, dates and numbers are sample values. Every phone is interactive, and all use the same floating tab bar: Home · Interviews · Jobs · Interests · Profile. Chat opens from the header button, so no tab is lit there.

My interviews

What the screen has today

  • Filters with counts: All, Upcoming, Completed, Cancelled
  • Per row: date, when, status, length · tier, interviewer once revealed, feedback note, action
  • “Book an interview” button; empty state “Nothing booked yet.”
Profile

Account + profile in one place

  • Name, mobile and email, each with Verified / Verify
  • My profile, edit steps, videos, applications, connections, notifications, stats
  • Receipts, visibility, notification settings, data rights, sign out
Chat

Three kinds of thread

  • Employer (their company name), your interviewer (masked until it starts), Apostrophe Support
  • Unread chip, archived section, read-only rules
  • Tap a row to open the conversation

My interviews

Tap a filter, a day or a row. Each row opens the interview’s detail with the real rules and actions for its status.

Profile

The Profile tab. Tap rows for their destination, flip the segmented control in option D, or tap an Edit link.

Chat

Tap any conversation. The interviewer thread is masked as “Your Interviewer”; the archived one is read-only.
