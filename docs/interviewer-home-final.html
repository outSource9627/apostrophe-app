Interviewer app · Home · final

Home, compact grid, premium

Option D from the design round, polished. Reads GET /interviewers/me and /config. Names, times, rupee amounts and counts are placeholder-shaped samples; the interviewer app shows full candidate names. Switch the state, scroll the phone, tap anything.

Type scale (this pass)
  • Greeting 30/700 (time of day and date from the device clock; the dashboard carries no name, so none is shown) with a 15/500 date line.
  • Stat tiles: figure 33/700 Geist, tight tracking, tabular; label 14/500 sentence case; compact tile: row 1 is a 20px tinted icon chip (13px glyph) inline with the 14/500 label, row 2 is the figure (size-steps 33 / 29 / 26 / 22 for long values). Height follows content (about 88px), 14px 16px padding, 5px row gap, 18px radius, 10px grid gap, equal heights per row only. The dashed Proposal tag now straddles the top edge of its tile.
  • Next-session card (24px radius, 16px 20px padding, 12px gaps): countdown 54 mono, “to start” 14, name 23/700, tier · domain · languages 15, status pill 12, join button 56px high with a 17/700 label.
  • Scorecards owed: section title 19/700 with a count chip; candidate 16.5/600, meta 14, clock pill 13 mono; rows 68px min, 12px 18px padding.
  • Smallest mono text anywhere on Home is 11.5 (the Proposal tag and the NEXT label at 12). Hairline borders, no shadows. Tab bar and status bar unchanged.
  • Empty, suspended, loading and error states use the same scale (24/700 titles, 16 body, 52px retry).
What changed vs. option D
  • Next-session card: the countdown is the hero, then a divider, full candidate name and tier · domain · languages, then the join button.
  • Status pill on the card (Join locked, Join open, In progress, Closed, Paused) so the state reads before the button does.
  • Join button states are distinct: locked = muted with lock and a live “Join opens in mm:ss”; open = white with a green dot; rejoin = violet with a white dot; closed and suspended = locked and not tappable.
  • Tile labels are now sentence case (“Done”, “On-time”) rather than mono caps; dashed proposal tiles sit last, with a wash fill.
  • Owed scorecards sit in one grouped card with a count, hh:mm:ss clocks in pills (red pill and soft red wash when urgent), closed rows muted without a pill.
  • The title bar “Home” fades in once you scroll (the existing compact-header pattern). Countdowns tick in this mockup.
Real content (in the app today)
  • DONE, COMPLETION, ON-TIME (a dash when the server has none) and the month’s earnings (label “THIS MONTH” with none).
  • Next session: start time (weekday added when not today), countdown, join button counting down to joinOpensAt, “Rejoin room”, “Join window closed”, disabled when suspended.
  • No booking: “No interviews booked.” plus open-slot copy and “Open more hours” / “Publish hours”.
  • Owed rows: “₹… releases on submit” or “Submit to close the interview”, own deadline as hh:mm:ss, urgent under the config reminder hours; “Closed · fee withheld” at 00:00:00; “None to write. Every scorecard is in.”
  • Suspension band, loading and “Couldn’t load your home.” with Try again. A forced password change redirects before Home draws.
  • Samples: join window, scorecard window, urgent threshold and fees are admin config values.
