Interviewer screening test

27 Oct 2026. Applicant screens (app and website) and the admin panels for the screening test you approved. The applicant only ever sees "Submitted", the pass mark is a guide for the admin, and questions come from the Claude question bank (a second blind check drops any question it disagrees with). Numbers marked setting are admin settings drawn with example values; the questions, scores, counts and costs are samples, not real data. Blue numbers mark what is new.

Generate a set

One call makes 15 technical questions for the domain plus 5 reasoning, 5 IQ and 5 general knowledge. A second call answers each one blind and drops any it disagrees with. Takes about a minute; about $0.50.

Data Science

CancelGenerate
No editing of question textOnly Disable / Enable, with an optional note. An edited question would no longer be what Claude and the answer check agreed on; a bad one is disabled and replaced by the next refill.
Cost is the API's own usageEach generation stores the tokens Claude reports; the dollar figure is computed from them. Nothing here is estimated by hand.
Settings are admin settingsCounts, time, guide, link days and refill level are read by the app and website from /config; the model comes from the server's env.
