2 · Admin: daily card limit (replaces the 2 / 200 counter)

The limit is already an admin setting: employer.rateLimit.cardsPerDay = 200. Setting it to 0 today means "no cards at all", not "no limit". So I propose an on/off switch next to the number and turning it Off now. The number is kept for when you switch it back on. The toggles below are clickable.

Admin › Settings › Employer  ·  sketch only; the real row uses the admin panel's existing setting controls

What the app does with cards OffNo counter on the card (removed either way). No "That's 200 today" screen. The feed keeps loading pages until it runs out ("You're caught up").
Per-employer overridesThe employer page can already set a different number for one employer. Proposal: an override still applies when the switch is off, so you can still limit one abusive account.

3 · Interviewer live room (APK)

Today the candidate gets the top ~55%, the controls take a band, and Script/Notes/Profile are squeezed into the bottom ~32%. New: the candidate fills the screen. Two buttons at the bottom open Notes or Profile in a sheet, and you switch between them inside the sheet. On the "New · live" phone, tap Notes or Profile to open the sheet, and ✕ to close it.
