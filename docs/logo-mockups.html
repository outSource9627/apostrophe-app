Lenient — 5 logo ideas

Each idea has an italic mark (slanted 12°, so it leans with the letters) and an italic wordmark. Where a mark has a letter inside, it is italic too. The dot on the i carries the brand colour. Colours are today's red #B22222 and ink #141414.

  • Fonts are free Google Fonts with true italic cuts. Before shipping, the chosen wordmark should be converted to SVG paths so the app and web don't need to bundle the font.
  • The marks are drawn shapes on a 100×100 grid, so the picked one can replace LogoMark (src/components/Logo.tsx) and the web logo directly.
  • Link one idea only: ?logo=1 … ?logo=5. Page chrome: ?theme=dark.
